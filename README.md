# KIXNEST

Curated thrift sneakers in Pakistan. Enquiries through WhatsApp.

## Website files

- `index.html` — complete static website
- `assets/logo.webp` — KIXNEST logo
- `assets/shoes.webp` — sneaker image

Open `index.html` in a browser, or serve this folder with any static web server. No build step is required.

This repository contains a copy of the existing KIXNEST website. Changes made in ChatGPT Sites are not automatically synchronized to this repository. Creating this repository does not enable GitHub Pages or change the existing live website.
